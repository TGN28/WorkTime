# Mitwirken an WorkTime

Vielen Dank für dein Interesse an WorkTime! Hier erfährst du, wie du zum Projekt beitragen kannst.

## Entwicklungsumgebung einrichten

_Wird nach Auswahl des Technologie-Stacks aktualisiert_

## Code-Style

- Verwende aussagekräftige Variablen- und Funktionsnamen
- Kommentiere komplexe Logik
- Halte Funktionen klein und fokussiert
- Schreibe Tests für neue Features

## Pull Request Prozess

1. Erstelle einen Feature-Branch von `main`
2. Implementiere deine Änderungen
3. Füge Tests hinzu
4. Aktualisiere die Dokumentation
5. Erstelle einen Pull Request mit klarer Beschreibung

## Commit-Nachrichten

Verwende aussagekräftige Commit-Nachrichten:
- `feat: Neue Feature-Beschreibung`
- `fix: Fehler-Beschreibung`
- `docs: Dokumentations-Änderung`
- `test: Test hinzufügen oder ändern`
- `refactor: Code-Verbesserung`

## Fragen oder Probleme?

Erstelle ein Issue im GitHub-Repository.

## Code of Conduct

Sei respektvoll und konstruktiv in der Kommunikation.
